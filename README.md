# Yazıcı testi

Saha telefonlarından Epson LX-350 nokta vuruşlu yazıcıya Bluetooth adaptörü üzerinden basılıp basılamadığını
denemek için tek sayfalık araç.

- Telefonda **Chrome** ile açın: https://boonfresh.github.io/yazici-testi/
- Sayfa yalnızca örnek (sahte) bir fatura basar; hiçbir sunucuya veri göndermez.
- Bu depodaki sayfa yalnızca yayın kopyasıdır.
